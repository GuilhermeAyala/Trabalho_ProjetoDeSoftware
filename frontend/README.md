# Frontend VITTA

Aplicativo mobile em React Native com TypeScript, criado a partir do fluxo de usuário do Figma.

## Pastas

- `src/components`: componentes visuais reutilizáveis.
- `src/data`: dados mockados usados nas telas.
- `src/navigation`: configuração de rotas, tabs e stack.
- `src/screens`: telas do aplicativo.
- `src/theme`: tokens de cor, espaçamento e tipografia.
- `src/types`: tipos compartilhados entre telas, mocks e navegação.

## Rodando

```bash
cd frontend
npm install
npm expo start - pra rodar o código
```

O backend em `../src` e a pasta `../prisma` não são usados nem modificados por este frontend.
