- [ ] Publicar o vídeo no YouTube como **Não listado** e inserir o link logo após os integrantes.
- [ ] Testar o link do vídeo sem autenticação; duração aproximada de 15 minutos.
- [ ] Adicionar `docs/BMC.pdf` ou `docs/BMC.md` atualizado.
- [ ] Adicionar obrigatoriamente `docs/DADOS.pdf`.
- [ ] Conferir se propostas antigas, diagramas e respectivos arquivos editáveis estão em `docs/`.
- [ ] Confirmar com o professor se uma aplicação desktop é exigida para este grupo. Nenhuma implementação desktop foi encontrada.
- [ ] Executar API, Web e App seguindo exclusivamente os READMEs de cada pasta.
- [ ] Confirmar que as três aplicações consomem a mesma API e respeitam os perfis de acesso.
- [ ] Gravar no vídeo somente funcionalidades realmente disponíveis para execução.
- [ ] Executar `./validar-entrega.ps1` na raiz e resolver todos os erros.
- [ ] Gerar o ZIP com `./criar-entrega.ps1` para excluir `node_modules`, `.env`, builds e metadados locais.
- [ ] Abrir o ZIP gerado, conferir a estrutura e garantir que o responsável envie o arquivo completo no AVA até **25/11/2026 às 23h59**.
